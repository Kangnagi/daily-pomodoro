## 0. 한눈에 보기

```
공부·운동 타이머 시간 ─┬─▶ 뽀모도로 화폐 ──▶ 상점 구매 / 뽑기 ──▶ 아이템
                       ├─▶ 경험치 ──▶ 레벨업 ──▶ 보상(화폐·뽑기권·칭호·아이템)
                       └─▶ 업적 달성 ──▶ 칭호 + 경험치
                                                  ▼
                                  내 프로필 (캐릭터 + 미니룸 꾸미기)
```

### 결정된 사항 (2026-11-09 상의)
| 항목 | 결정 |
|---|---|
| 화폐 단위 | 토마토 조각(1시간)을 추가해 4단계: 조각 → 초록 → 노랑 → 빨강 |
| 운동 시간 | 공부와 똑같이 화폐·경험치를 줌. **타이머로 잰 시간만** 셈 (직접 입력한 유산소 시간 제외) |
| 지난 기록 | 처음 켤 때 지금까지의 기록을 화폐·경험치·업적으로 한 번에 정산 |
| 그림 | 코드로 그리는 **도트(픽셀) 그림** (이모지 없음) |
| 프로필 위치 | 위쪽 바에 프로필 버튼 추가 → 사용자가 보고 수정 요청 |
| 만드는 순서 | 1단계 보상 뼈대 → 2단계 프로필·꾸미기·상점 → 3단계 뽑기·아이템 확장 |

## 1. 뽀모도로 화폐

### 1-1. 단위
| 화폐 | 기준 시간 | 합치기 |
|---|---|---|
| 토마토 조각 | 1시간 | 10개 → 초록 1개 |
| 초록 뽀모도로 | 10시간 | 5개 → 노랑 1개 |
| 노랑 뽀모도로 | 50시간 | 2개 → 빨강 1개 |
| 빨강 뽀모도로 | 100시간 | 최고 단위 |

### 1-2. 얻는 방법
- **공부:** 뽀모도로 기록의 집중 시간 (일시정지 제외, 지금 기록되는 `minutes` 그대로)
- **운동:** 운동 타이머로 잰 운동 시간 (`sessions[].minutes`). 운동 일지에 직접 적은 유산소 시간은 세지 않음
- 휴식 시간은 세지 않음
- 60분이 모일 때마다 조각 1개. 남은 분은 다음으로 이월 → 프로필에 "다음 조각까지 23분" 진행 바
- 보너스: 업적 달성, 레벨업 보상으로도 받음

### 1-3. 잔액 계산 방식 (제안)
- **번 화폐 = (공부 + 운동 타이머 총 분 ÷ 60)의 몫 + 보너스 합**, **잔액 = 번 화폐 − 쓴 화폐**
- 이렇게 "기록에서 계산"하면 기록을 지우거나 고쳐도 화폐가 저절로 맞음. 따로 화폐를 더하고 빼는 방식보다 어긋날 일이 없음
- 지운 기록 때문에 이미 쓴 화폐보다 번 화폐가 적어지면 잔액이 0 아래로 내려가지 않게 0으로 보여 주고, 다음 공부부터 메꿈

### 1-4. 합치기 방식 — **정할 것 ①**
| 방식 | 설명 |
|---|---|
| A. 자동 (추천) | 내부에서는 조각 단위로 저장하고, 화면에는 항상 큰 단위부터 보여줌 (예: 조각 137개 → 빨강 1 · 노랑 0 · 초록 3 · 조각 7). 살 때도 알아서 계산 |
| B. 직접 합치기 | 조각 10개가 모이면 "합치기" 버튼이 생기고 누르면 반짝이며 초록으로 바뀜. 대신 초록 가격 아이템을 빨강으로 살 때 거스름 규칙이 필요 |

## 2. 경험치와 레벨

- **경험치:** 타이머 시간 1분 = 1 경험치 (공부·운동 공통) + 업적 보너스
- **레벨업에 필요한 경험치:** 레벨 n → n+1에 `60 × (n + 1)` (점점 늘어남)
  | 레벨 | 누적 필요 경험치 | 대략 시간 |
  |---|---|---|
  | 2 | 120 | 2시간 |
  | 5 | 840 | 14시간 |
  | 10 | 3,240 | 54시간 |
  | 20 | 12,540 | 209시간 |
  | 30 | 27,840 | 464시간 |
- **레벨업 보상**
  - 매 레벨: 토마토 조각 2개
  - 5레벨마다: 뽑기권 1장 + 레벨 칭호 (예: Lv.5 "새싹", Lv.10 "꾸준러", Lv.20 "집중의 달인")
  - 10레벨마다: 레벨 전용 아이템 1개 (상점에 없는 것)
- 레벨업 순간: 축하 창 + 받은 보상 목록

## 3. 업적과 칭호

업적마다 **칭호 1개 + 경험치 보너스**. 프로필에서 칭호 하나를 골라 캐릭터 위에 표시.

| 분류 | 업적 (예시) | 칭호 (예시) | 보너스 경험치 |
|---|---|---|---|
| 처음 | 첫 뽀모도로 완료 | 첫걸음 | 30 |
| 처음 | 첫 운동 기록 | 땀 한 방울 | 30 |
| 공부 누적 | 10 / 50 / 100 / 300 / 500시간 | 공부 입문자 / 성실한 학생 / 100시간의 주인공 / 공부 장인 / 전설의 수험생 | 100 / 300 / 600 / 1000 / 2000 |
| 운동 누적 | 10 / 50 / 100시간 | 운동 입문자 / 땀의 기록 / 강철 체력 | 100 / 300 / 600 |
| 연속 | 3 / 7 / 30 / 100일 연속 공부 | 작심삼일 극복 / 일주일 개근 / 한 달의 기적 / 백일의 약속 | 50 / 150 / 500 / 1500 |
| 연속 | 7 / 30일 연속 운동 | 운동 습관 / 운동 중독 | 150 / 500 |
| 하루 | 하루 4 / 8시간 공부 | 몰입 / 공부 기계 | 100 / 300 |
| 시간대 | 오전 6시 전에 공부 시작 | 새벽형 인간 | 100 |
| 시간대 | 자정 넘어 공부 | 올빼미 | 50 |
| 목표 | 하루 목표 달성 10 / 50번 | 목표 달성러 / 목표 사냥꾼 | 150 / 500 |
| 시험 | 시험 결과 "합격" 기록 1 / 3번 | 합격자 / 합격 수집가 | 500 / 1500 |
| 운동 | 몸무게 기록 30번 | 기록하는 몸 | 200 |
| 운동 | 한 종목 최고 무게 경신 10번 | 기록 갱신자 | 300 |
| 아케이드 | 뽑기 첫 회 / 아이템 30개 모으기 | 뽑기 초보 / 수집가 | 30 / 300 |
| 숨은 업적 | 조건을 숨겨 둔 업적 몇 개 | ? | ? |

- 업적 화면: 달성한 것(날짜)과 아직인 것(진행률 바 "47 / 100시간")
- 달성 순간: 알림 띠(토스트 대신 위에서 내려오는 업적 배너)

## 4. 지난 기록 정산 (처음 한 번)

1. 아케이드 기능이 들어간 버전을 처음 켜면 지금까지의 공부·운동 타이머 기록을 모두 계산
2. 화폐·경험치·레벨을 한 번에 반영하고, 조건을 이미 채운 업적을 모두 달성 처리 (달성 날짜는 실제 조건을 채운 날로)
3. "지난 기록으로 받은 보상" 창: 받은 화폐, 레벨, 달성한 업적 수
4. 정산은 한 번만 (다시 켜도 중복 지급 없음). 1-3의 "기록에서 계산" 방식이면 따로 중복 걱정이 없음

### 5-3. 꾸밀 수 있는 것
| 분류 | 자리 | 예시 |
|---|---|---|
| 캐릭터 | 머리, 표정, 상의, 하의, 모자, 손 소품 | 단발, 웃는 얼굴, 후드티, 안경, 연필 |

| 방 소품 | 정해진 자리 6곳 (벽 2, 바닥 3, 책상 위 1) | 책상, 책장, 화분, 시계, 포스터, 고양이 |

- 그림: 코드로 그리는 도트 그림. 캐릭터 32×32, 미니룸 160×120 정도를 크게 확대해서 보여줌. 모든 아이템이 같은 그림체

## 6. 상점과 뽑기

### 상점
- 등급·분류별 목록, 가진 화폐로 살 수 있는 것만 진하게 표시
- 상점 물건 일부를 매주 바꾸는 "이번 주 상품"은 나중에 검토

### 뽑기
- 1회: 조각 5개 / 10회: 조각 45개 (1회 할인)
- 10회 뽑기에는 희귀 이상 1개 확정
- **천장:** 50회 안에 전설이 안 나오면 50번째는 전설 확정
- **중복:** 이미 가진 아이템이 나오면 조각으로 돌려줌 (일반 1 · 희귀 3 · 영웅 8 · 전설 20)
- 등급별 확률은 뽑기 화면에 항상 공개
- 뽑기권(레벨업 보상)으로 1회 무료

## 8. 만드는 순서

### 1단계 — 보상 뼈대
- 화폐 계산(공부+운동 타이머), 경험치·레벨, 업적·칭호
- 지난 기록 정산 + 정산 결과 창
- 업적 달성·레벨업 알림
- 위쪽 바 프로필 버튼 + 간단한 프로필 화면 (닉네임, 레벨·경험치 바, 지갑, 다음 조각까지, 업적 목록, 칭호 고르기)
- **확인:** 사용자가 위쪽 바·프로필 화면을 보고 수정 요청

### 2단계 — 프로필 꾸미기 + 상점
- 도트 그림 그리는 엔진 + 기본 캐릭터·미니룸
- 첫 아이템 세트 (캐릭터 15개, 배경 8개, 소품 15개 정도)
- 꾸미기(가진 아이템 입히기·놓기), 상점 구매

### 3단계 — 뽑기 + 아이템 확장
- 뽑기 (확률 공개, 10회 확정, 천장, 중복 환급, 뽑기권), 뽑기 연출
- 아이템 추가, 레벨 전용 아이템, 숨은 업적

## 9. 아직 정할 것

1. **화폐 합치기 방식:** A 자동 (추천) / B 직접 합치기 (1-4)
2. **가격·확률·레벨 곡선:** 위 숫자는 예시. 1단계를 써 보면서 조정
3. **닉네임:** 프로필에 닉네임 칸을 둘지 (기본값 "나")
4. **업적 목록:** 3장의 예시에서 더하거나 뺄 것
5. **미니룸 분위기:** 그림체 참고(싸이월드 미니룸처럼 비스듬한 방 / 정면에서 본 방)
