## 2. 겪은 문제와 원인 (다시 겪지 않도록)

1. **태엽 소리 무음 (가장 오래 걸린 문제)**
   ffmpeg로 0.47~0.80초를 자를 때 `-ss`를 입력 뒤에 두고 `afade=st=0.31`을 걸어서, 페이드가 원본 기준 0.31초에 이미 끝나 클립 전체가 0이 됨.
   재생 함수 호출·스피커 연결만 확인하고 실제 소리 크기를 재지 않아서 여러 번 놓침. → 이후 모든 소리는 측정으로 확인.
   (자를 때는 `-ss`를 `-i` 앞에 두고, 결과의 peak가 0이 아닌지 반드시 확인)
2. **앱(WebView)에서 약 30초 조용하면 스피커 연결이 끊김**
   `dumpsys audio`에서 releasing player 후 재생해도 new player가 안 생김. → 조용했으면 suspend/resume으로 재연결 + 타이머 화면에서는 들리지 않는 신호로 연결 유지(keepAlive).
3. **모바일 브라우저 자동재생 정책**: pointerdown은 사용자 동작으로 인정 안 됨 → 문서 전체의 첫 pointerup/click/keydown에서 오디오 깨우기.
4. **로컬 알림 플러그인**: 정확한 알람 권한이 없으면 예약할 때마다 설정 화면을 띄움 → USE_EXACT_ALARM 추가.
   울린 알림은 cancel로 안 지워짐 → removeDeliveredNotifications 사용.
5. **안드로이드 알림 채널은 소리·진동을 나중에 못 바꿈** → 새 채널 ID(focus-end-2)로 만들고 예전 채널 삭제.
6. **이 PC의 npm**: `npm`이 조용히 아무것도 안 함 → `node npm-cli.js`로 실행.
7. **웹 캐시**: 서비스 워커가 브라우저 HTTP 캐시의 오래된 JS를 돌려줌 → SW fetch에 `cache: "no-cache"`.
9. **직접 만든 플러그인 가져오기**: Capacitor 8 웹 쪽엔 `registerPlugin`이 없어 앱 시작 시 오류 → `Capacitor.Plugins.TimerNotice`로.
8. **에뮬레이터 탭 테스트가 빗나감**: 꿀팁 바가 두 줄이 되면서 캘린더 날짜 칸 좌표가 바뀜 → 좌표는 매번 스크린샷으로 확인.
