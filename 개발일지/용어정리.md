# 용어 정리

개발하면서 나온 현상·기능을 부르는 이름을 모아 둔 곳.
다음에 요청할 때 "이런 거"를 이 이름으로 말하면 바로 통한다.
(새 용어가 나오면 아래 표에 계속 추가. 번호는 개발기록 번호와 연결)

## 스크롤

| 용어 | 뜻 (이 앱에서의 예) | 이렇게 요청하면 됨 | 개발기록 |
|---|---|---|---|
| 스크롤 체이닝 (scroll chaining) | 안쪽 스크롤 상자를 끝까지 넘긴 뒤 더 끌면 남은 스크롤이 바깥 화면으로 넘어가 화면 전체가 움직이는 현상. 칭호 목록 끝에서 더 내리면 프로필 화면이 내려가던 것 | "○○ 목록 스크롤 체이닝 막아줘" / "목록 안에서 스크롤할 때 바깥 화면이 따라 움직이지 않게 해줘" | #63 |
| 오버스크롤 (overscroll) | 스크롤이 끝(맨 위·맨 아래)에 닿은 뒤에도 더 끄는 동작. 안드로이드에서는 끝에서 물결처럼 번쩍이는 효과도 이렇게 부름 | "오버스크롤 효과 없애줘" | #63 |
| 안쪽 스크롤 영역 (중첩 스크롤) | 화면 안에서 따로 스크롤되는 상자. 칭호 목록처럼 화면 전체와 별개로 움직임 | "칭호 목록을 안쪽 스크롤 영역으로 만들어줘" | #62 |
| 스크롤 표시 화살표 (스크롤 힌트) | 스크롤바 대신 더 볼 내용이 있는 쪽에 보이는 화살표. 칭호 목록 위·아래 가운데의 ⌃ ⌄ | "스크롤바 대신 스크롤 힌트 화살표로 보여줘" | #62 |
| 페이드 마스크 | 스크롤 상자 가장자리를 배경색으로 서서히 가려 잘린 내용이 자연스럽게 보이게 하는 것. 칭호 목록 화살표 뒤 그라데이션 | "가장자리 페이드 넣어줘" | #62 |
| 보이는 영역 (뷰포트, viewport) | 스크롤 상자나 화면에서 지금 눈에 보이는 부분. 칭호 목록을 닫을 때 이 영역 안의 칭호만 하나씩 사라지게 함 | "보이는 영역(뷰포트) 기준으로만 애니메이션 해줘" | #66 |

## 애니메이션

| 용어 | 뜻 (이 앱에서의 예) | 이렇게 요청하면 됨 | 개발기록 |
|---|---|---|---|
| 스태거 (stagger, 순차 등장) | 여러 항목이 동시에가 아니라 조금씩 시간차를 두고 하나씩 나타나거나 사라지는 효과. 칭호 목록이 하나씩 나타나고 아래부터 하나씩 사라지는 것 | "목록 항목이 스태거로 하나씩 나타나게 해줘" | #59, #60 |
| 아코디언 (펼침/접힘) | 버튼을 누르면 상자가 위에서 아래로 펼쳐지고 다시 누르면 접히는 UI. 프로필의 칭호 목록 | "아코디언처럼 펼쳐지게 해줘" | #59 |
| 이징 (easing) | 움직임의 속도 곡선. ease는 천천히 시작해 빨라졌다 느려지고, linear는 처음부터 끝까지 같은 속도. 칭호 상자가 접힐 때 처음이 느려서 멈춘 것처럼 보이던 원인 | "처음부터 일정한 속도로 움직이게(linear) 해줘" | #61 |
| 애니메이션 딜레이 / 틈 | 두 움직임 사이에 아무것도 안 움직이는 빈 시간. 칭호가 다 사라진 뒤 상자가 접히기 전까지의 멈칫함 | "두 애니메이션이 겹치게(동시에) 이어지게 해줘" | #61 |

## 표시·강조

| 용어 | 뜻 (이 앱에서의 예) | 이렇게 요청하면 됨 | 개발기록 |
|---|---|---|---|
| 배지 (badge) | 항목 모서리에 붙는 작은 꼬리표. 새 칭호 왼쪽 위의 NEW | "왼쪽 위에 NEW 배지 붙여줘" | #64 |
| 글로우 (glow) | 테두리나 글자 주변이 빛나 보이게 퍼지는 그림자 효과. 새 칭호의 주황 테두리 | "테두리에 글로우 효과 넣어줘" | #64 |
| 펄스 (pulse) | 밝아졌다 어두워졌다를 계속 반복하는 깜빡임. 새 칭호 글로우가 은은하게 반복되는 것 | "글로우가 펄스처럼 반복되게 해줘" | #64 |
| 읽음 처리 (seen 상태) | 새 항목을 한 번 보면 '봤음'으로 기록해 다음부터 NEW를 숨기는 것. 칭호 목록을 한 번 열면 NEW가 사라지는 것 | "한 번 보면 읽음 처리해서 NEW 없애줘" | #64 |

## 개발·오류

| 용어 | 뜻 (이 앱에서의 예) | 이렇게 요청하면 됨 | 개발기록 |
|---|---|---|---|
| 캐시 (cache) | 한 번 받은 파일을 저장해 두고 다시 쓰는 것. 빠르지만 파일을 고친 뒤에도 예전 파일이 쓰일 수 있음 | "캐시 때문인지 확인해줘" | #65 |
| 강력 새로고침 (hard reload) | 캐시를 무시하고 모든 파일을 서버에서 새로 받아 다시 여는 것. PC 브라우저에서 Ctrl+Shift+R (또는 Ctrl+F5) | "강력 새로고침해도 그래" | #65 |
| 버전 섞임 (버전 불일치) | 일부 파일은 새 버전, 일부는 예전 버전이 불러와져 서로 안 맞는 상태. 칭호 목록이 안 열린 원인 | "파일 버전이 섞인 것 같아" | #65 |
| 콘솔 오류 (console error) | 화면에는 안 보이지만 브라우저 안쪽에 기록되는 프로그램 오류 메시지. 버그 원인을 찾을 때 가장 먼저 보는 곳 | "콘솔 오류 확인해줘" | #65 |

## 그림 (도트·이미지)

| 용어 | 뜻 (이 앱에서의 예) | 이렇게 요청하면 됨 | 개발기록 |
|---|---|---|---|
| 도트 그림 (픽셀 아트) | 작은 네모 칸(픽셀)을 하나씩 칠해서 그린 그림. 화폐 토마토, 토마토 조각, 뽑기권 | "16×16 도트로 그려줘" | #70 |
| 코드로 칠하기 (SVG 방식) | 그림을 파일로 넣지 않고 "어느 칸에 무슨 색"을 코드에 적어 앱이 직접 그리는 방식. 지금 화폐 그림이 이 방식 | "코드로 칠하는 방식(SVG)으로 넣어줘" | #70 |
| 이미지 파일 첨부 (PNG 방식) | 그림판 등으로 그린 PNG 파일을 앱 폴더에 넣고 그대로 보여 주는 방식 | "이 PNG 파일 그대로 넣어줘" | #70 |
| 팔레트 (palette) | 그림에 쓰는 색 모음. 토마토 조각은 8색 팔레트 | "팔레트를 이 색들로 바꿔줘" | #70 |
| 투명 배경 | 그림이 없는 칸을 비워 두어 뒤 배경이 보이게 한 것. PNG로 저장할 때 선택 | "배경 투명하게 저장해서 줄게" | #70 |
| 흐림 방지 (nearest / pixelated, crispEdges) | 작은 도트 그림을 크게 키울 때 칸 경계가 뿌옇게 번지지 않고 또렷한 네모로 보이게 하는 설정 | "도트가 흐리게 보여, 또렷하게 해줘" | #70 |
